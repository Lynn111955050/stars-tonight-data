# 觀星App天象資料

這是獨立於App程式的公開天象清單，不含使用者位置或帳號資料。

更新sky_events.json並增加revision整數即可；schemaVersion保持1。保留事件id，修正日期或文字時不要換id；移除事件代表撤回。每筆需要id、title、kind、note、source、start、end，日期包含+08:00時區且end晚於start；請核對天文館或IMO來源。

清單由手機連線取得，失敗時沿用已保存版本，仍受手機系統排程及網路限制，非即時推播服務。不要放任何密碼、金鑰或個人資料。


## 三階段提醒

一般日期型事件：該日臺灣時間08:00及前三天08:00提醒；資料沒有確切時刻時，不發「當下」通知。

查證時刻後，可新增notifyAt（含時區的ISO時間）及timeSource（查證來源HTTPS網址）。notifyAt必須落在start至end之間；前三天改依notifyAt減72小時，當天08:00提醒（若事件早於08:00，改00:00），並於notifyAt提醒。預報時刻不等於保證精準極大或當地一定可見。午夜安靜模式仍優先，過期階段不補發。

可選regions陣列，每項包含south、north、west、east，限制適用位置；缺省表示既有臺灣規劃範圍（21.5–26.5N、118–122.5E），不是逐地可見度計算。通知依手機最近查詢座標比對範圍，加入該地預報及地點限制；不儲存使用者位置到此資料庫。
